    Up and running in two minutes.

    DoDaily isn't on the Play Store yet, so you install the APK straight from GitHub.

    Download

    Grab the latest .apk from Releases on your phone.

    Install

    Open it. Allow "Install unknown apps" for your browser if Android asks.

    Add the widget

    Long-press your home screen → Widgets → DoDaily → drag it out.

    Allow reminders

    Open the app once and tap Allow on the notification and alarm banners.

    Samsung / Xiaomi / OnePlus: these phones kill background alarms to save battery. Set DoDaily's battery usage to Unrestricted so reminders show up on time.
